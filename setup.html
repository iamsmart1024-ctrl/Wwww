설정 가이드

5분이면 끝납니다. 순서대로 따라하세요.

1. Supabase 프로젝트 생성

  1. supabase.com 가입 → New Project
  2. Region은 Northeast Asia (Seoul) 추천
  3. DB 비밀번호는 안전한 곳에 보관

2. SQL 실행 (테이블/RLS/Storage 한방에)

  1. 좌측 메뉴 → SQL Editor → + New query
  2. 이 폴더의 schema.sql 전체를 복사해서 붙여넣고 Run
  3. "Success. No rows returned" 가 뜨면 OK

3. URL/Key 연결

  1. Project Settings → API 에서 Project URL 과 anon public key 복사
  2. config.js 파일을 열어 두 값을 본인 것으로 교체
window.SUPABASE_URL  = "https://xxxxx.supabase.co";
window.SUPABASE_ANON = "eyJhbGciOi....";

4. 이메일 인증 끄기 (중요)

아이디 기반 로그인이라서 이메일 인증이 켜져 있으면 가입이 막힙니다.

  1. Authentication → Providers → Email
  2. Confirm email 토글을 OFF

5. 멘토 계정 생성

  1. 사이트 접속 → 회원가입 탭
  2. 아이디 dhlee1024, 비밀번호 smartboy1024! 로 가입
  3. DB 트리거가 자동으로 role='mentor' 부여
멘토 계정은 단 하나입니다. 가입 후엔 다른 사용자는 dhlee1024 아이디를 못 씁니다.

6. GitHub Pages 배포 (선택)

  1. 레포의 Settings → Pages → Source: 작업 브랜치 선택
  2. 몇 분 뒤 https://<계정>.github.io/<레포>/ 로 접속

영상 파일 크기 안내

Supabase 무료 플랜은 파일당 50MB 까지입니다. 큰 강의 영상은:

  • Supabase Pro 플랜 (5GB/파일)
  • 또는 HandBrake 등으로 압축 (720p, H.264, CRF 23 정도면 50MB 안쪽 가능)
